## 1. Filosofi Pembelajaran Tak Terawasi (Unsupervised Learning)

Dalam dunia industri riil, data berlabel (*annotated ground truth*) sangat langka dan mahal untuk diproduksi. Sebaliknya, data mentah tanpa label melimpah ruah.

**Pembelajaran Tak Terawasi** bertujuan mengekstraksi struktur intrinsik, pola segmentasi tersembunyi, atau relasi alami di dalam data tanpa adanya bimbingan variabel target (`y`).

### Kasus Penggunaan Klastering:
- **Segmentasi Pelanggan (Customer Profiling)**: Mengelompokkan pengguna berdasarkan pola transaksi untuk strategi pemasaran personal.
- **Deteksi Anomali Jaringan**: Mendeteksi paket data aneh yang tidak masuk ke kelompok lalu lintas normal.
- **Sistem Kompresi Citra**: Kuantisasi warna berbasis vektor centroid.

---

## 2. Pembedahan Algoritma K-Means & K-Means++

K-Means mempartisi `N` sampel data ke dalam `K` kelompok yang saling lepas (*mutually exclusive*) dengan meminimalkan jumlah kuadrat jarak titik ke pusat klasternya (**Within-Cluster Sum of Squares - WCSS / Inertia**):


$$
\text{WCSS} = \sum_{k=1}^{K} \sum_{x \in C_k} ||x - \mu_k||^2
$$


### A. Alur Kerja Standar:
1. Menentukan jumlah klaster $K$.
2. Menginisialisasi posisi $K$ titik centroid secara acak.
3. Menugaskan setiap titik data ke centroid terdekat berdasarkan jarak Euclidean:
   
$$
d(x, \mu) = \sqrt{\sum_{j=1}^{p} (x_j - \mu_j)^2}
$$

4. Menghitung ulang koordinat centroid baru sebagai rata-rata (*mean*) dari semua anggota klaster tersebut.
5. Mengulangi langkah 3 dan 4 hingga konvergen (posisi centroid tidak lagi bergeser signifikan).

### B. Masalah K-Means Klasik & Solusi K-Means++
Inisialisasi centroid murni acak dapat menjebak algoritma pada **Optimum Lokal (Local Minima)** yang buruk. 
**K-Means++** memecahkan masalah ini dengan memilih titik centroid awal yang tersebar sejauh mungkin satu sama lain menggunakan distribusi probabilitas sebanding dengan kuadrat jarak $D(x)^2$.

## 3. Menentukan Jumlah Klaster Optimal ($K$)

Karena algoritma tidak mengetahui jumlah kelompok sebenarnya, praktisi menggunakan dua metrik evaluasi matematis:

### 1. Metode Siku (Elbow Method)
Memplot grafik antara nilai $K$ dan $\text{WCSS}$. Titik di mana penurunan kurva melambat drastis (membentuk pola siku) dipilih sebagai jumlah klaster paling efisien.

### 2. Koefisien Siluet (Silhouette Coefficient)
Mengukur seberapa mirip suatu objek dengan klasternya sendiri dibandingkan dengan klaster tetangga terdekatnya:

$$
s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}, \quad -1 \le s(i) \le 1
$$


- `a(i)`: Rata-rata jarak titik `i` ke semua titik lain dalam klaster yang sama (*intra-cluster distance / kohesi*).
- `b(i)`: Rata-rata jarak titik `i` ke titik-titik pada klaster terdekat lainnya (*inter-cluster distance / pemisahan*).
- `s(i) \approx +1`: Sampel terklaster secara sangat rapat dan terpisah sempurna.
- `s(i) \le 0`: Sampel kemungkinan besar salah masuk kelompok.

## 4. Klastering Berbasis Kerapatan: DBSCAN

K-Means mengasumsikan bahwa semua klaster berbentuk bulat sferis (*convex*) dan memiliki ukuran kerapatan yang seragam. Jika kelompok data berbentuk arbitrer (seperti bulan sabit atau cincin konsentris), K-Means akan gagal total.

**DBSCAN (Density-Based Spatial Clustering of Applications with Noise)** mengatasi kelemahan ini dengan mengelompokkan data berdasarkan kerapatan titik:
- **`\epsilon` (Epsilon)**: Radius jarak pencarian tetangga.
- **`\text{MinPts}`**: Jumlah minimum titik dalam radius `\epsilon` untuk membentuk area rapat.
- Titik yang tidak memiliki tetangga cukup diklasifikasikan sebagai **Noise / Pencilan (Label: -1)** secara otomatis.

## 5. Implementasi Python: Evaluasi K-Means vs DBSCAN

```python
"""
Eksperimen Klastering Komparatif: K-Means++ vs DBSCAN
Disusun oleh: Mahendar Dwi Payana
"""

import numpy as np
import pandas as pd
from sklearn.datasets import make_moons
from sklearn.cluster import KMeans, DBSCAN
from sklearn.metrics import silhouette_score
from sklearn.preprocessing import StandardScaler

def evaluate_clustering_algorithms(X):
    # Penskalaan fitur wajib dilakukan untuk algoritma berbasis jarak!
    X_scaled = StandardScaler().fit_transform(X)
    
    # 1. K-Means (K=2)
    kmeans = KMeans(n_clusters=2, init='k-means++', n_init=10, random_state=42)
    labels_km = kmeans.fit_predict(X_scaled)
    sil_km = silhouette_score(X_scaled, labels_km)
    
    # 2. DBSCAN
    dbscan = DBSCAN(eps=0.3, min_samples=5)
    labels_db = dbscan.fit_predict(X_scaled)
    # Evaluasi siluet tanpa titik noise (-1)
    mask = labels_db != -1
    if len(set(labels_db[mask])) > 1:
        sil_db = silhouette_score(X_scaled[mask], labels_db[mask])
    else:
        sil_db = 0.0
        
    print("=" * 60)
    print("PERBANDINGAN KINERJA ALGORITMA KLASTERING")
    print("=" * 60)
    print(f"K-Means++ (K=2) : Silhouette Score = {sil_km:.4f}")
    print(f"DBSCAN          : Silhouette Score = {sil_db:.4f} (Titik Noise: {(labels_db == -1).sum()})")
    print("=" * 60)

if __name__ == "__main__":
    # Buat dataset non-sferis (bentuk dua bulan sabit)
    X, _ = make_moons(n_samples=600, noise=0.08, random_state=42)
    evaluate_clustering_algorithms(X)
```
