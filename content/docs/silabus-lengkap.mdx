## Matriks Kurikulum 18 Pertemuan

| Sesi | Topik Pertemuan | Capaian Pembelajaran (*Learning Outcome*) | Alokasi JP |
| :---: | :--- | :--- | :---: |
| **01** | **Setup Lingkungan Komputasi Modern & Tools AI** | Menyiapkan interpreter Python 3.11+, environment virtual (`uv`/venv/conda), JupyterLab, VS Code, Google Colab, serta akselerasi GPU (CUDA/MPS). | 2 JP Kelas<br />4 JP Mandiri |
| **02** | **Konsep Dasar, Teknologi & Aplikasi AI** | Memahami 4 kuadran definisi AI, arsitektur agen cerdas PEAS, 7 tipe lingkungan tugas, taksonomi problem-solving, ekosistem Industri 4.0, dan Stranas KA 2020-2045. | 2 JP Kelas<br />4 JP Mandiri |
| **03** | **Metodologi Pengembangan Sains Data Berbasis Data** | Menguasai metodologi industri (CRISP-DM, KDD, SEMMA, TDSP), 7 langkah generik end-to-end, serta studi kasus Python terpadu data imunisasi bayi DKI 2016. | 2 JP Kelas<br />4 JP Mandiri |
| **04** | **Kakas Proyek Sains Data (Tools for Data Science)** | Menguasai keunggulan Python, ekosistem IDE/Colab, Git/GitHub, 6 pustaka inti, vektorisasi NumPy vs List TypeError, analisis `Tab.csv` dan `pmp_2020_baru.csv`, serta modul notebook resmi. | 2 JP Kelas<br />4 JP Mandiri |
| **05** | **Business Understanding & Rencana Proyek AI** | Merumuskan AI vs otomasi, paradigma end-to-end ML, analisis biaya finansial asimetris, dan perancangan proyek AI nyata (Saham Tata Global & Kendaraan Otonom). | 2 JP Kelas<br />4 JP Mandiri |
| **06** | **Data Understanding (Non-Visualisasi)** | Menguasai 4 skala Stevens, 3 model data terstruktur, teknik akuisisi data multi-sumber, statistik deskriptif non-visual, studi kasus karakteristik mobil (`automobileEDA.csv`) dan performa pemain EPL. | 2 JP Kelas<br />4 JP Mandiri |
| **07** | **Exploratory Data Analysis & Visualisasi Data Statistik** | Menguasai visualisasi variabel vs statistik, uji hipotesis ANOVA satu arah F-test (penggerak roda mobil), dan penyelesaian tuntas 5 latihan notebook statistik resmi (`05124873011-3.ipynb`). | 2 JP Kelas<br />4 JP Mandiri |
| **08** | **Data Preparation: Penentuan Objek, Pembersihan & Validasi Data** | Menentukan objek data via sampling (probability vs non-probability), penanganan imbalanced dataset (SMOTE), 3 teknik seleksi fitur (Chi2, Extra Trees, Heatmap), serta praktik pembersihan dataset riil (British Library, University Towns, Olympics). | 2 JP Kelas<br />4 JP Mandiri |
| **09** | **Konstruksi & Transformasi Data Numerik** | Melakukan normalisasi, standarisasi (MinMax, Robust, Standard Scaler), serta transformasi distribusi (Log, Box-Cox, Yeo-Johnson). | 2 JP Kelas<br />4 JP Mandiri |
| **10** | **Feature Engineering, Encoding, Integrasi Data & Labeling** | Melakukan encoding fitur kategorikal (One-Hot, Dummy, Target), integrasi tabel (Merge & Join), ekstraksi fitur dengan PCA, Pseudo-Labelling, seleksi fitur, serta menetapkan label target. | 2 JP Kelas<br />4 JP Mandiri |
| **11** | **Skenario Model & Pemodelan Klasifikasi** | Merancang skenario validasi (Train-Validation Split, K-Fold, Scikit-learn Pipeline) dan melatih serta menuning model klasifikasi (Logistic Regression, SVM, Decision Tree, Naive Bayes, KNN, AdaBoost) pada dataset Iris. | 2 JP Kelas<br />4 JP Mandiri |
| **12** | **Pemodelan Regresi Numerik** | Melatih model regresi linier sederhana & variabel jamak, regresi polinomial/non-linier, SVR, Decision Tree, dan Random Forest Regression; menguji asumsi klasik Gauss-Markov serta mengevaluasi dengan MAE/MSE/RMSE/R². | 2 JP Kelas<br />4 JP Mandiri |
| **13** | **Unsupervised Learning & Klastering** | Melakukan segmentasi data tak terawasi menggunakan K-Means++, Hierarchical Agglomerative, DBSCAN, serta evaluasi Silhouette. | 2 JP Kelas<br />4 JP Mandiri |
| **14** | **Deep Learning & Artificial Neural Networks** | Memahami Perceptron, Multilayer Perceptron, fungsi aktivasi, Backpropagation, gradient descent, adaptive learning rate (Adam), lalu menerapkan ANN, CNN (Conv/Pooling), dan RNN dengan Scikit-learn, PyTorch & Keras 3. | 2 JP Kelas<br />4 JP Mandiri |
| **15** | **Evaluasi Diagnostik & Review Model** | Mengevaluasi performa model melalui Confusion Matrix, Precision/Recall/F1, ROC-AUC, PR-Curve, Log Loss, metrik regresi (MAE/MSE/RMSE/R²), metrik clustering (Silhouette/Davies-Bouldin), perbandingan model (McNemar's Test), serta interpretasi fitur dengan SHAP. | 2 JP Kelas<br />4 JP Mandiri |
| **16** | **Model Deployment Web & MLOps** | Memahami konsep & pola deployment (static, dynamic on-device/on-server), strategi Single/Silent/Canary, reproducibility, serialisasi model (`joblib`/`.keras`/ONNX), serta mendeploy model Regresi Linier & ANN ke web (Flask/Docker, FastAPI/Streamlit) beserta pemantauan drift. | 2 JP Kelas<br />4 JP Mandiri |
| **17** | **Transformer, LLM & Prompt Engineering** | Memahami mekanisme Self-Attention & arsitektur Transformer, tokenisasi BPE, tahapan pelatihan LLM (Pretraining, SFT, RLHF/DPO), teknik Prompt Engineering (Zero-Shot, Few-Shot, CoT), dan keluaran terstruktur JSON/Pydantic via API Python. | 2 JP Kelas<br />4 JP Mandiri |
| **18** | **RAG, AI Agents & Evaluasi Sistem LLM** | Memahami Text Embeddings & pencarian semantik, membangun pipeline RAG end-to-end, Function Calling (Tool Use) & pola AI Agents, serta evaluasi RAG Triad dan mitigasi risiko *Prompt Injection*. | 2 JP Kelas<br />4 JP Mandiri |

- **Pembelajaran Mandiri (Hands-on & Proyek)**: 18 sesi × 4 JP = **72 JP**
- **Total Beban Pembelajaran**: **108 Jam Pelajaran (JP)** (@ 45 menit/JP)
